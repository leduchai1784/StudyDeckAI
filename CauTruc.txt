studydeckai/
CẤU TRÚC THƯ MỤC FLUTTER — 3 TARGET DÙNG CHUNG 1 CODEBASE:
  1) Mobile app (Android/iOS)     -> lib/main_mobile.dart
  2) Web app người dùng (PWA)     -> lib/main_web.dart
  3) Web Admin quản trị           -> lib/main_admin.dart
Cả 3 dùng chung core/ + models/ + services/ + features/ + shared/,
khác nhau ở entry point và bộ route/layout được nạp (responsive cho web).

GHI CHÚ TRIỂN KHAI 3 TARGET:
- Build Mobile:      flutter build apk --target=lib/main_mobile.dart
                      flutter build ios --target=lib/main_mobile.dart
- Build Web người dùng: flutter build web --target=lib/main_web.dart --output=build/web-user
- Build Web Admin:      flutter build web --target=lib/main_admin.dart --output=build/web-admin
  (2 bản Web build ra 2 thư mục riêng, deploy lên 2 domain/subdomain khác nhau,
   ví dụ app.studydeck.ai và admin.studydeck.ai)
- lib/admin/ tuyệt đối không import vào main_mobile.dart / main_web.dart để tránh
  lộ code quản trị vào app công khai và giảm dung lượng bundle không cần thiết.
- features/ được viết responsive (dùng shared/responsive/) để tái sử dụng gần như
  100% giữa Mobile và Web người dùng, chỉ khác nhau ở shared/layouts/ (Bottom Nav
  vs Sidebar/Topbar) và một số tương tác đặc thù nền tảng (ghi âm, chọn file...).
